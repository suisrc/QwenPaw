# weather-query 开发说明


## Python 执行方式
在 QwenPaw 环境下使用 `python`，不要用 `python3`。

```bash
source .venv/bin/activate
python scripts/weather_query.py "大连"
```

不传参数时会提示输入城市名称：

```bash
python scripts/weather_query.py
```

也可以作为模块执行：

```bash
python -m scripts.weather_query
```

## 返回值标准化
脚本内部先返回标准化结果，再做终端友好展示。

成功示例：

```python
{
    "success": True,
    "data": {
        "city": "大连",
        "location_name": "大连",
        "country": "中国",
        "region": "辽宁",
        "weather": "局部多云",
        "temperature": "18°C",
        "feels_like": "17°C",
        "humidity": "72%",
        "wind_direction": "NE",
        "wind_speed": "14 km/h",
        "precipitation": "0.0 mm",
        "pressure": "1012 hPa",
        "update_time": "09:00 AM"
    },
    "raw": {}
}
```

失败示例：

```python
{
    "success": False,
    "data": None,
    "error": "无法获取城市天气：大连"
}
```
